# Quick Start Guide

## Getting Started in 30 Seconds

### 1. Open the Website
Double-click `index.html` or open it in your browser:
```
File → Open → index.html
```

### 2. Explore the Names
- **Scroll down** to see all 99 Divine Names
- **Hover** over any name to see its invocation
- Names are displayed with Arabic text, English translation, and meanings

### 3. Use Navigation
When you scroll past the introduction banner:
- **Goto field** (right side): Enter 1-99 to jump to any name
- **Toggle buttons**: Click to show/hide additional information:
  - Title
  - Description
  - Malayalam (alternate language)
  - Benefits

### 4. Start Recitation
Click the **"START RECITATION"** button to jump to the first Divine Name

## Key Features

### Interactive Hover Effects
Point your mouse at any Divine Name card to:
- See the invocation ("Ya [Name] Ya ALLAH")
- Display name highlighting in status bar

### Information Toggles
After scrolling, click the option buttons to show/hide:
- **Description**: Detailed explanation of the name
- **Benefits**: Spiritual benefits of reciting that name
- **Malayalam**: Malayalam language translation

### Jump to Any Name
Use the input field labeled "Goto:" to jump directly to a specific Divine Name by its number (1-99).

## Keyboard Navigation

- **Tab**: Move between interactive elements
- **Enter**: Activate buttons and start recitation
- **Number keys**: Quick navigation (when using Goto field)

## Mobile Tips

- Works on all smartphones and tablets
- Responsive design adapts to screen size
- Touch instead of hover for card information
- Swipe to scroll through names

## Viewing Full Content

Information sections (Description, Benefits, Malayalam) are hidden by default for a clean interface. Click the option buttons in the header to reveal them:

1. Scroll down to show the options bar
2. Click "Description" to see full explanations
3. Click "Benefits" to see spiritual benefits
4. Click "Malayalam" to see alternative translations

## Troubleshooting

### Page won't load?
- Make sure all files are in the correct directories
- Check that `assets/css/`, `assets/js/`, and `assets/images/` folders exist
- Refresh the page (Ctrl+R or Cmd+R)

### Names not appearing?
- Check browser console for errors (F12)
- Ensure JavaScript is enabled
- Try a different browser

### Images not loading?
- Verify `assets/images/` folder exists
- Check image file names haven't changed
- Clear browser cache and reload
